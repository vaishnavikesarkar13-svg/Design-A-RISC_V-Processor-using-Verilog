# Design-A-RISC_V-Processor-using-Verilog
RISC-V processor is an open source RISC (Reduced Instruction Set Computer) instruction set architecture (ISA). A single cycle processor is a type of CPU design where each instruction is fetched,decoded and executed in one clock cycle. In single cycle implementation, the CPU does all steps of an instruction in a single ,fixed length clock pulse.
That means a single cycle RISC-V processor is a simple CPU design where every instruction whether arithmetic, logic,memory access or branch is fetched, decoded, executed and completed within a single clock cycle.
Its datapath typically includes a Program Counter (PC), instruction memory, a register file (32 general-purpose registers in RISC-V), an ALU, data memory, sign-extension units, control logic, multiplexers, and adders for branch target calculation.
